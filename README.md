## 🔥 Why This Exists

Searching for "free ATAS" or "TradingView Premium crack" in 2026 is dangerous. Security researchers documented a wave of malware disguised as cracked trading software — the payload steals passwords, cookies, and crypto wallets. The people behind these "cracks" are not helping traders. They are hunting them.

At the same time, there are excellent open-source terminals that most traders don't know about:

- **Depth** — a local, multi-exchange terminal that streams 10 venues into one order book. No server, no account. Runs on macOS, Windows, and Linux.
- **HypeTerminal** — an open-source Hyperliquid client with full order support and multi-wallet signing.
- **Tradoor** — a browser-based terminal with TradingView-style charts, market profile, and liquidations.

This launcher puts them in one place. One EXE. Three terminals. Zero cracks.

## 🧩 What It Does

### Terminal Browser
- List of open-source terminals with descriptions and source links
- Version tracking for each terminal
- Direct link to GitHub releases

### One-Click Launch
- Download the latest release of a selected terminal
- Extract to a local folder
- Launch without manual setup

### Safety Check
- Warns if a user tries to add a "cracked" or "paid" terminal to the list
- Explains why cracked terminals are dangerous (with links to security research)
- Recommends open-source alternatives

### Local-Only Mode
- All terminals run locally
- No relay servers, no accounts required for market data
- API keys stored locally (if the terminal supports it)

## ❓ FAQ

**Does this crack paid software?**
No. It does the opposite — it surfaces open-source alternatives and warns against cracks.

**Why not just download Depth directly?**
You can. This launcher is for people who want a curated, safe starting point without hunting through GitHub. It also keeps terminals updated.

**Are these terminals safe?**
They are open-source and inspectable. Depth runs locally with no server. HypeTerminal is a public monorepo. Tradoor is open-source.

**Do I need API keys?**
For market data, no. For trading, you need exchange API keys. The terminals handle this locally.

**Will I get banned by exchanges?**
These are official clients that use exchange APIs. No ban risk. They don't exploit or manipulate.

**How do I uninstall?**
Delete the launcher folder. Downloaded terminals remain in their own folders.
